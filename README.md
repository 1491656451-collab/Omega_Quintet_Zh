# 欧米伽五重奏 简体中文汉化补丁

《Omega Quintet》（Steam / PC 版）的简体中文汉化补丁。

**差分补丁**：只包含被修改过的归档成员，不含完整游戏数据。安装时逐成员校验原版 MD5，
对不上就一个字节都不写 —— 所以**必须有正版游戏才能用**。

---

## 下载与安装

到 [Releases](../../releases) 下载 `欧米伽五重奏_简体中文汉化_v1.4.zip`。

1. 确认游戏没在运行；
2. 解压，双击 **`安装汉化.bat`**；
3. 它会自己找游戏目录；找不到就把游戏目录拖进窗口再回车
   （例如 `D:\SteamLibrary\steamapps\common\Omega Quintet`）；
4. 看到「装好了」就完事，进游戏。

**卸载**：双击 `卸载汉化.bat`，逐字节还原成原版。
补丁会在游戏目录留下 `.oqundo` / `.oqundo3` 还原文件，别删。
真删了也不要紧 —— 在 Steam 里「验证游戏文件完整性」就能回去。

> ### ⚠ 从 v1.0 ~ v1.3 升级：必须先卸载再装
> 先双击 `卸载汉化.bat` 等它还原完，再双击 `安装汉化.bat`。
> 不先卸载的话安装器会报「和原版对不上」并且**一个字节都不写** —— 那是安全设计，不是坏了。

## 适用版本

Steam 版，`OmegaQuintet.exe` MD5 `5ab6f76d830e68266bdea6a2f790ed96`。
其它版本（或游戏更新之后）安装器会拒绝写入。

## 保持英文的部分

不是漏了，是有原因的：

| 位置 | 原因 |
|---|---|
| 设置界面部分文案、存档/读档文本、Quit to Desktop、五句教程提示、DLC 礼包表 | 这些是 PC 移植版**写死在 `OmegaQuintet.exe` 里**的，而 exe 外面套着 SteamStub，校验范围包含 `.rdata` —— 改一个字节游戏就起不来（实测两次，报 `Application load error 3:0000065432`）。**可以用下面的可选补充包在运行时解决** |
| `BREAK` / `LIVE` / `Chain!!` / `Turn Back!!` / `Wait Damage!!` / `Hit` / `Total Damage` / `Magnetic Field` / `Support Rate` / `Play Time` 等 | 美术字横幅与风格化标签，改成中文反而不好看，按观感保留 |
| `Chara select` / `Main Mission` / `Arcanium` / `collect!!` / `ATTACK!` 等 | 在 `grSystemWindow.dds` 上，未处理 |
| 地图光点拾取横幅上的 DLC 道具名 | 同样来自 exe 里的礼包表，改不了 |
| `HP` `SP` `EP` `LV` `EXP` `MAX` `Coins` `PV`、指北针 `N/E/S/W` | 按惯例保留 |

## 可选：PC 汉化补充包（exe 内文本）

上表第一行那些「改不了」的 exe 内文本，可以用一个**可选的运行时补充包**解决：
`欧米茄五重奏_PC汉化补充.zip`，同样在 [Releases](../../releases)。

它是一个代理 `dinput8.dll`，在游戏启动时把 exe 里写死的 **45 条界面文本**
（设置七项与说明文、窗口/无边框/全屏、启用/禁用、确定/取消、按键重映射提示、
全部存读档文本、退出至桌面、五句教程提示）和 **37 个 DLC 礼包的名称与说明**
在内存里换成中文。装法就是把包里两个文件丢进游戏根目录，卸载就是删掉它们。

> ### ⚠ 装之前请读完
>
> - **没有经过实机验证**，当前这个版本一次都没真正跑过。
> - 它会往游戏进程内存里写数据：转发 `DirectInput8Create` → 读 `oq_exe_dlc_zh.tsv`
>   → `VirtualAlloc` 放中文串 → 用 `VirtualProtect` 改 exe `.data` 段里
>   **45 + 74 个写死地址**的指针。没有网络连接，没有自启，不碰游戏目录以外的文件。
> - **但它没有源码。** 这是个编译好的二进制，上面那些行为是反汇编逐条读出来的，
>   **任何人都无法从源码重新构建它**。不接受这一点就别装 —— 主补丁不依赖它。
> - **杀毒软件可能报警。**「游戏目录里放一个同名系统 DLL」+「往别的进程内存里写东西」
>   正好是 DLL 劫持和修改器的典型特征，报警是合理的启发式判断。
> - 地图光点拾取横幅上的 DLC 道具名**仍然是英文**。原先有一套运行时内存扫描来处理它，
>   但那套扫描会让游戏在启动后十秒内崩溃（有两份崩溃转储为证），已经关掉。
> - 只对 `OmegaQuintet.exe` MD5 `5ab6f76d830e68266bdea6a2f790ed96` 有效，游戏一更新就得删掉。

## 中文字体

游戏用的是自有的点阵字体格式 `.ffu`，不是 TTF。补丁把 `window\font\sysfont.ffu`（菜单，
汉字 24×30 px）和 `window\font\advfont.ffu`（对话框，汉字 35×44 px）里
**20,924 个 CJK 字形用 [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk) Black 重新渲染**了一遍。

游戏是日/韩/英三语发行，字库里本来就有三万个 CJK 槽位，但简体里有一多半汉字在日文字库中没有
字形（槽位存的是半角空占位）。已有的汉字也一起重渲染，否则中日两种字形混在一行里笔画粗细对不上。

Noto Sans CJK 采用 [SIL Open Font License 1.1](https://openfontlicense.org/)。

## 技术说明

补丁格式 **OQPATCH3** —— 按成员名寻址的 `.bra` 差分补丁：

- 只含改过的成员，不含游戏原档；
- 每条记录带**原始 MD5 与新 MD5**，应用前逐成员核对，对不上整包拒绝写入；
- 新压缩块塞不回原槽位时追加到文件末尾并改索引（中文字体体积翻倍，必须支持这个）；
- 写入后回读校验，失败自动回滚；重复安装幂等。

逆向与制作过程见 [`docs/制作过程.md`](docs/制作过程.md)。

### v1.4 修了什么

菜单 1083 / 1084 / 1085（委托的「击破」「交付」目标）和 1062（技能升级说明）这 4 条译文里，
`%d` 和 `%s` 的顺序被写反了。游戏用 `sprintf` 拼这几句，于是 `%s` 会拿到一个整数，
`strlen((char*)1)` 读地址 `0x1` —— **打开「委托」必崩**。

```
错误: 击破%s %s %d 只（%d/%d）      参数: 1, '击败ＭＡＤ', '幼虫', 0, 1
正确: 击破 %d 只 %s %s（%d/%d）
```

v1.0 ~ v1.3 都有这个问题。现在出包前会跑一道闸，比对全部 22,606 条译文与英文原文的
**转换符种类与顺序序列**（只比个数是抓不到这类错误的）。

## 关于分发

本补丁是《Omega Quintet》的衍生作品。它不含完整游戏数据，但确实包含游戏原有资源的
**修改副本**（重渲染的字库、改过文字的贴图、回填译文的数据表）。
本仓库未附带开源许可证 —— 给一个衍生作品挂 MIT/GPL 会产生误导。
使用者请自行确认所在地区的相关规定。
